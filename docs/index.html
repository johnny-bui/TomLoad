04 — Presets

One engine, four glyph voices.

Tap a voice — the card runs a real cycle right away: scrambles out, shows a glyph field while “fetching”, then decodes in with that voice.

idle
inkCondenses .:-=+*#@, then letters and digits. Product UI, dashboards.
ditherShaded blocks ░▒▓█; images keep their colors. Image-heavy cards.
spark* + ✦ ✧ in the accent color. Festive and playful brands.
binary0 and 1 in the accent color. Dev tools, fintech.
const g = glyph(card, { preset: 'spark' });

await g.hide();                 // scramble out
g.loading(true);                // glyph field while fetching
const data = await fetchProduct();
render(card, data);
g.loading(false);
await g.reveal({ origin: 'top' });
05 — Skeletons

Paints on the first frame. No JavaScript loop.

skeleton() returns static glyph rows with a pure-CSS sweep — it renders on the server and costs nothing while it waits. Press Load to swap each one for real data.

import { skeleton } from 'tomload';

el.innerHTML = skeleton({ variant: 'braille', lines: 4 });   // dots · blocks · binary · braille · plus
el.innerHTML = skeleton({ variant: 'blocks', rows: 8 });     // image / avatar block
06 — Install

Four steps. Works with any stack.

1Install

From GitHub with npm, or drop the browser build into any page — WordPress, Webflow, plain HTML.

npm i github:johnny-bui/TomLoad

# or, no build step
<script src="https://cdn.jsdelivr.net/gh/johnny-bui/TomLoad@main/dist/tomload.iife.js"></script>

2Paint a skeleton

Static markup, shows instantly while your request is in flight.

import { glyph, skeleton, mascots } from 'tomload';

card.innerHTML = skeleton({ variant: 'dots', lines: 4 });

3Load with a mascot

Render the real markup, keep it hidden, show a mascot drawn through the glyph grid.

card.innerHTML = renderProduct(data);
const g = glyph(card, { preset: 'ink' });
g.hide({ instant: true });
g.loading(true, { mascot: mascots.phin });

4Decode in

Text, images and canvases land in place. Buttons and icons fade in on the wave.

g.loading(false);
await g.reveal({ origin: 'top', speed: 0.6 });
07 — API

Small on purpose.

MethodWhat it does
glyph(el, options)Create a controller for any element.
reveal({ origin, speed })Decode content in. Resolves when everything landed.
hide({ instant })Scramble out, or hide instantly. Content stays in the DOM.
loading(on, { mascot })Glyph field or mascot while data loads. Sets aria-busy.
update(options)Change options, e.g. the preset.
destroy()Stop and restore the element.
skeleton(spec)Static glyph skeleton HTML with a CSS sweep.
OptionDefault
preset'ink' · 'dither' · 'spark' · 'binary' · object
speed1 — wave speed multiplier
origin'top' · 'center' · 'pointer' · {x, y}
accent--tl-accent — scramble glyph color
mediaimg, canvas, video, [data-tl="media"]
fadesbutton, svg, [data-tl="fade"]
// A mascot is any draw function: (ctx, width, height, seconds) => void
const pulse = (ctx, w, h, t) => {
  ctx.fillStyle = '#7b6cff';
  ctx.beginPath();
  ctx.arc(w / 2, h / 2, Math.min(w, h) * (0.25 + 0.05 * Math.sin(t * 4)), 0, Math.PI * 2);
  ctx.fill();
};
g.loading(true, { mascot: pulse });
