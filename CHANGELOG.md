# Changelog

## 0.1.0 — 2026-10-25
- First public release: `glyph()` controller (`reveal`, `hide`, `loading`, `update`, `destroy`), `skeleton()` with 5 CSS-only variants.
- Presets: `ink`, `dither`, `spark`, `binary`.
- Mascots: Vietnam set (`phin`, `hat`, `lantern`) and Holiday set (`snowman`, `tree`, `gift`).
- Docs site in `docs/` (GitHub Pages).
